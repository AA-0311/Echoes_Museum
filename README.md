## 📖 About the Museum

**Echoes** is an experimental, interactive virtual installation mapping the spaces within the human heart through raw volumetric structural arrangements and the rich tapestry of Indian history, art, and architecture. 

It is designed as a fully client-side Single Page Application (SPA) that takes the visitor on a curated journey across different "Wings", each representing a distinct human emotion. Through stunning visuals, micro-animations, and historical context, Echoes transcends a traditional gallery to become an architectural mapping of feelings.

## 🗺️ Exhibitions

The museum is divided into active wings, each unlocking sequentially as you progress through your journey:

*   ✨ **Wonder**: Architectural marvels and ancient ingenuity (Taj Mahal, Ellora Caves).
*   🛡️ **Courage**: Tales of bravery and historic forts (Rajputana Forts, Maratha Empire).
*   🎉 **Joy**: The vibrant colors of celebration (Holi, Mughal Paintings).
*   ❤️ **Love**: Legends of romance and devotion (Heer Ranjha, Poems of Meera Bai).
*   🌱 **Resilience**: Standing strong through the test of time (Jallianwala Bagh, Earthquake-proof Temples).
*   🌅 **Hope**: Looking towards a brighter dawn (India-Pakistan Partition resilience, Classical Dance Forms).

## ✨ Features

*   **Interactive SPA Routing**: Custom-built Vanilla JavaScript router enabling seamless transitions between wings without page reloads.
*   **Dynamic Theming**: The entire museum's color palette, CSS variables, and ambient glow shift dynamically based on the emotional theme of the current exhibit.
*   **Immersive Animations**: Silky smooth scroll animations, hovering interactive elements, and staggered view transitions powered by GSAP.
*   **Virtual Map**: An interactive architectural blueprint allowing visitors to visualize their journey and jump between unlocked exhibits.
*   **Certificate of Exploration**: Upon completing the final exhibit quiz, a personalized, downloadable "Certificate of Exploration" is generated dynamically in the browser using the HTML5 `<canvas>` API.

## 🛠️ Tech Stack

This project was built focusing on maximum performance, aesthetic brilliance, and zero backend dependencies:

*   **Core**: HTML5, Vanilla CSS3 (Custom Properties, Glassmorphism, CSS Grid/Flexbox)
*   **Logic**: Vanilla JavaScript (ES6+)
*   **Routing**: Custom Client-Side Router via HTML5 History API
*   **Animations**: GSAP (GreenSock Animation Platform) & ScrollTrigger

## 🚀 Getting Started

Since Echoes is a completely static, client-side application, running it locally is incredibly simple.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/echoes.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd echoes
   ```
3. **Run the Museum:**
   You can simply double-click the `index.html` file to open it in your browser! or `node server.js` in the root directory
